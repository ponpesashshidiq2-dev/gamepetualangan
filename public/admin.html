Informasi Sistem

  • Backend: PHP (api.php) — tanpa Node.js, cocok untuk hosting shared (cPanel).
  • Penyimpanan: file JSON di folder data/ (di luar root web bila memungkinkan; bila di dalam, dilindungi .htaccess).
  • Password admin: data/config.json (atau ubah lewat form di samping).
  • Format CSV soal: id, pertanyaan, tipe, opsi1..opsi4, kunci, poin, kategori, aktif.
  • Kunci isian: beberapa jawaban benar dipisah |, contoh: Tokyo|Tokio.
  • Backup: salin seluruh isi folder data/.

Tambah Soal

Import Soal

Tempel langsung dari Microsoft Word, atau tempel/pilih file JSON atau CSV. Baris CSV: id, pertanyaan, tipe, opsi1..opsi4, kunci, poin, kategori, aktif (baris judul wajib ada).

Dari Word: blok teks soal lalu Ctrl+C, tempel di kotak ini. Opsi yang ditebal / digarisbawahi otomatis dijadikan kunci. Tanpa baris opsi = soal isian. Pisahkan soal dengan baris kosong.
